# ansible-role-edge-shield (`v1.1.0`)

Official Ansible Role and Go configuration helper for deploying **Utilvo EdgeShield** across Ubuntu, Debian, and RHEL Nginx servers. Installs O(1) `geo` and `map` directives blocking rotating-IP headless scrapers (**Tencent Cloud `AS132203`**, **Alibaba Cloud `AS45102`**, **Huawei Cloud `AS136907`**) with 6-hour automatic threat feed synchronization and 100% search engine crawler safety (`Googlebot`, `Bingbot`, `Applebot`, `DuckDuckBot`).

- **Official Interactive Firewall Builder & Log Analyzer:** [https://utilvo.com/edge-shield](https://utilvo.com/edge-shield)
- **Live ASN/CIDR Threat Feed API:** [https://utilvo.com/api/edge-shield/threats](https://utilvo.com/api/edge-shield/threats)
